2026-11-08。検証対象はv0.11.2、コミット`3278b32cde4c88ffd17421028f2dc0838c49bb78`の実装です。今回の変更は検証記録の整理だけです。

| 旧監査の指摘 | 現行での判定 |
| --- | --- |
| optional/lazyなAI用CLIP接続が、AIモデル未導入時の通常生成を止める | 修正済み。`prompt_queue.prepare_video_prompt`を実行前検証フックに登録し、動画実行リクエストからEngineのAI用入力だけを除外。保存Workflowの配線は保持します。 |
| 全体OFFでも明示AI要求を送信できる／画面に全体スイッチがない | 現行のボタン仕様。原文／AI文は欄ごとの動画生成用テキスト選択、AI生成は明示実行です。「原文」はAI機能全体の禁止スイッチではありません。以前の全体OFF案と区別します。 |
| AI生成後に自動採用される | 現行のボタン仕様。AI生成成功後はAI文を選択し、表示中の文章を動画生成に使用します。原文は保持し、原文ボタンで切り替えます。承認用ボタンは追加しません。 |
| テンプレートenabled=trueと空Timelineの初期値が違う | enabledだけではAI推論を起動しません。textsが空なら原文を使用し、AI生成はボタン操作で実行します。設定値の差と実行動作を区別します。 |
| REPORTが旧版表記 | 修正済み。Engineは共通の`version.py`を参照。パッケージとREPORTは0.11.2で一致します。 |
| 一般名のテストログが100件／16件の古い結果のまま | 今回整理。旧ログに開発版2.0.0・2026-11-05の履歴である旨を追記し、今回の結果は版・日付付きファイルへ保存しました。旧結果本文は保持しています。 |

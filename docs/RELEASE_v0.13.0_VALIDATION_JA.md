# v0.13.0 AI指示・MP保持・チャンク境界補正の検証

2026-11-08。AI指示、MP変更後の保存AI文保持、チャンク境界補正を収録。最終公開ソースのCPU/JavaScript確認と、同じ機能コードを使ったWindows実機確認を区別します。実機確認時のREPORT版番号は0.12.0（ローカル修正版）で、公開時に0.13.0へ更新しています。

## 操作

- 普段は各文章欄の「AI生成」だけで動画向けの標準指示を使用します。上部の「AI指示」で指示を編集し「保存」。標準復帰、キャンセル、右上×、Escに対応します。既存のAI文は書き換えず、以後の生成へ適用します。
- AI指示はプロジェクトへ保存します。Engineの任意`ai_instruction`入力が接続されている場合は外部を優先し、Studio内の指示も保持。外部の空文字は標準指示を使用します。
- 外部STRINGの上流だけを明示AI操作時に実行。通常動画の入力検証からAIモデル・AI指示依存を除き、原文での通常生成を維持します。モデル入力など本来必須の検証は保持します。
- 共通AIは共通文だけ、ショットAIはショット本文だけを変更。共通文ONのショットAIには共通文を背景情報として渡しますが、共通文を変更しません。
- StudioのMPのみ変更した場合、保存AI文と原文／AI文の選択を維持します。時間・参照・アスペクト比・Engine側のサイズ変更など既存の条件検証は維持します。
- 継続時の境界補正は自動です。末尾2フレームと先頭5フレームだけで通常ContinuumのCPU評価・色補正を使い、先頭1フレームの孤立した明暗変化も安全判定付きで補正。接合時刻、音声、フレーム数、Sampler、Seed派生は変えず、場面転換へは適用しません。

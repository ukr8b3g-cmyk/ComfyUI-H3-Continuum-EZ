# H3 Continuum EZ Studio のリリース検証

## v0.10.1（2026-11-07）

- AIモデル未導入でも、保存用の配線を変えずに通常の動画生成ができるよう修正。
- 公開前の全Python 264件・JavaScript 77件成功。Coreの実入力検証でも欠落AIモデルの再現・解消と、必要なモデルの検査維持を確認。
- 普段のWindows ComfyUI 0.44.0 ClassicのStudioからLong video／Imagesを実行。AIモデルに存在しない名前を指定した検証用テンプレートで、H3 REF2VA＋Pika Flexの実GPU生成が両方成功。
- 各416×224、24fps、56フレーム、約2.333秒。動画とAAC 32kHz音声を全デコードし、Studioの再生・サムネイルからの途中再生も確認。
- 実生成は同じ修正コードを導入したv0.10.0のローカル修正版で実施。v0.10.1化では版番号・説明を更新。新たな長尺・多ショット試験やAIモデルの再推論は実施していません。

詳細は[AIモデル任意化の検証](OPTIONAL_AI_VALIDATION_JA.md)を参照してください。実画面はChrome自動接続のエラーにより、同一ComfyUIをアプリ内Chromiumから操作しました。

## v0.10.0（2026-11-07）

- WindowsでPython 253件、JavaScript 77件成功。テンプレートが1本であること、全27配線、6モデルの初期値、旧AI文の互換性を検証。
- 実ComfyUI Classicに新しいJSONを読み込み、Studioが2ショットの例文と素材未指定の状態で開くことを確認。この環境の拡散モデルとLoRAは共有サブフォルダーにあるため、配布既定値で実行するにはモデルの再選択が必要でした。
- 番号付きのREADME画面は利用者提供の操作例です。この版のGPU動画生成およびAI再推論は未実施です。

## v0.9.1

WindowsのComfyUI 0.44.0 Classicで、StudioからMiniMax H3 FL2VAの1ショットをLong videoで実行しました。EngineのIMAGEを接続したCreate Videoは出力先を空にし、EngineのVIDEOをSave Videoに直接つなぎました。保存MP4は416 × 224、24 fps、56フレーム、約2.33秒で、AACステレオ音声を最後までデコードできました。

Python 172件、JavaScript 32件が通過しました。素材操作の失敗通知は日英の分離試験で確認しました。今回の実機検証はこの短い1ショットが対象です。

## v0.9

2026-11-06。公開タグ `v0.9`、パッケージ版 `0.9.0`。開発版2.0.0のコードを基にした初回公開です。

| 確認 | 結果 |
| --- | --- |
| Python CPU | 169件成功。Sampler／VAEを模擬した境界試験とCPUでのMP4書き出しを含む |
| JavaScript | 32件成功。プロンプト、分割、プレビュー履歴、キュー照合、シード制御を含む |
| REF2VAテンプレート | 元の外側2本・サブグラフ内23本のリンクと既存ノード名を保持。モデル選択・5つの入手先・Timelineデータを照合 |
| Continuumの原コード | 同梱する継続処理15ファイルとストレージ5ファイルのSHA-256を出典記録と照合 |
| 配布物 | 配布用ZIPを開き、コミットの収録ファイルとSHA-256を照合 |

日本語／英語の分離Chromium画面で、動画比率、タイムラインとの連動、キューの表示、自動分割の設定を確認した開発版を使用しています。Windowsの実ComfyUI Classic（frontend 1.57.6）では、開発版のサブグラフでシード制御を操作し、保存されたJSONを確認しました。これらの範囲は[画面・キュー・分割の確認記録](PREVIEW_QUEUE_OPTIONS_JA.md)に記載しています。

新しいREF2VAテンプレートは、選択されていたREF2VA＋Pika Flex設定をサブグラフの内外でそろえ、個人素材への参照を除いた2ショットの例です。実際の生成では利用者の参照画像を指定してください。GPUを使う生成、公開テンプレートの実画面からのキュー実行、Nodes 2.0、長尺のピークRAM/VRAMは確認していません。

仕様策定時点の記録は[開発版の検証](VALIDATION_JA.md)、出典のハッシュは[継続エンジン](CORE_PROVENANCE.json)と[ストレージ](../vendor/continuum/STORAGE_PROVENANCE.json)を参照してください。

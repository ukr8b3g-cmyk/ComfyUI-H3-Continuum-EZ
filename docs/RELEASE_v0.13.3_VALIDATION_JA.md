# v0.13.3 Apply and Queue修正・検証

修正・ブラウザー確認：2026-11-09。公開準備：2026-11-10。v0.13.2のUIに対する限定修正です。

## 再現と修正

不正な分割間隔と、映像約5秒に音声60秒を置いた条件で、入力検査によってボタン自体が無効になることを分離Chromeで再現しました。「Not queued」の表示は変わらず、理由が離れたフッターに出るため分かりづらい状態でした。ユーザーが最初に提示した画像の入力全体は取得していないため、同一原因とは断定しません。

入力エラーではボタンを押して理由を確認できるようにし、アクションのそばに「入力を確認 / Check inputs」、ボタンと状態表示のマウスオーバーに理由を表示します。クリック時のローカル/サーバー入力検査は維持し、不正な内容をキューへ送りません。アップロード・反映・送信中だけ一時ロックし、完了/例外後の共通処理で復旧します。反映開始時にも直ちにロックします。

## 分離Chromeの確認

実Studioの画面・イベント処理を使用し、ComfyUIへの反映、キュー、AI、HTTP境界は代替した試験です。実GPU検証ではありません。

- 不正な分割間隔：クリック可能・反映/送信0。値を修正した後に送信可能。
- 音声が映像より長い：クリック可能・反映/送信0。「映像尺合わせ」後に送信可能。
- 反映失敗、キュー送信失敗、preflight通信失敗：ボタンは復旧し、再試行可能。
- 反映中/送信中：一時無効、完了後に有効。待機中の送信件数は増えず、二重送信を防止。
- AI処理中：動画反映/送信0。AI処理失敗後は原文で反映/送信可能。
- 日本語：「入力を確認」と具体的な理由を表示。

[観測値](RELEASE_v0.13.3_BROWSER_OBSERVATIONS.json)には途中の状態と再試行後の状態を区別して収録しています。件数をGPU成功件数とは扱いません。

修正を普段のComfyUIへ反映し、実ComfyUIのEZ_Audio_Volume_QAで修正済みのヘルプと有効なボタンを観測しました。その後はユーザーの「追加確認不要」の指定により実画面操作を終了。公開時にも追加の実画面確認・再起動・GPU生成は行っていません。

ネイティブファイル選択はブラウザーの選択操作でエラーになり未完了です。アップロード中/後の実操作を検証済みとは扱いません。検証用ローカルサーバーは終了し、プロセス終了とHTTP停止を確認しています。

JavaScriptの最終試験と、版番号/同梱Workflowの限定Python確認は添付ログに収録。生成コード全体のPython346件成功と実GPUの記録はv0.13.2時点の別記録です。今回はその全試験を再実行したとは扱いません。

モデル配線、シード、両テンプレート、Python生成処理、通常Continuum由来22モジュールを保持しています。新たな依存関係はありません。

# Studioのプロジェクト操作

Studio上部の「プロジェクト」メニューから操作します。日本語以外のロケールでは英語表示です。

- **新規プロジェクト / New Project**：空の素材・文章、5秒の1ショットから開始します。外部STRINGが接続されていても、新規プロジェクトの共通文は空のStudio本文を使用します。
- **プロジェクト保存 / Save Project**：保存ダイアログで`.h3ez.json`のファイル名と保存先を選びます。キャンセルすると編集中のプロジェクトに戻ります。保存ダイアログが使えない環境では、ブラウザーの設定に従ってダウンロードします。
- **プロジェクト読込 / Open Project…**：保存したファイルを選択します。形式・内容を検査してから現在の編集と置き換えます。不正なファイルは現在の編集を保持したまま拒否します。

ショット・共通文・原文／AI文と選択状態・参照画像の割当・開始／最終画像・カメラ・動作・台詞・音声の配置／トリム／音量・サイズ／出力形式／自動分割設定を保存します。

素材本体は埋め込まず、ComfyUIの入力フォルダー内のファイルを参照します。同じサーバーでの再編集を想定しています。別環境で開く場合は素材ファイルも別途移し、同じ相対パスへ置くか素材を差し替えてください。モデル配線・シード・外部STRINGノード・生成済み動画は保存対象に含みません。モデル配線・シードを変えずにStudioの編集だけを切り替える機能です。

未保存の編集がある場合、新規作成・読込の前に確認します。キャンセル・右上の×・Escでは編集を保持。置換を選ぶと新しい内容へ切り替え、「元に戻す」で切替前の編集を復元できます。素材読込・AI処理・反映処理の実行中は置換しません。

プロジェクト保存とノード反映は別の操作です。読込後の内容で生成するには「ノード反映」または「反映・キュー追加」を使います。ワークフロー全体も残す場合はComfyUI側で保存してください。入力ファイル上限は32 MiBです。音声が映像より長い編集中の状態も保存できますが、生成前には映像尺を合わせる必要があります。

## 確認範囲（2026-11-08）

既存を含むJavaScript 91件成功。長文・素材ID・音声編集・AI文を含む往復、不正／過大ファイル・安全でない素材パスの拒否を確認。

Chromeで製品のHTML/CSS/JSを使用した検証画面を操作し、新規、実ダウンロード、保存ファイルの再読込、未保存確認のキャンセル・右上の×・Esc・置換、Undo、不正ファイル後の本文保持、読込後のノード反映を確認しました。日本語・英語と1366×768のメニュー表示も確認しました。

この検証画面のComfyUI連携は代替です。普段のComfyUIへはファイルを反映・ハッシュ照合しますが、新しい機能での実GPU生成やユーザー保存Workflowの置換は行っていません。

# 継続境界の動き補正（v0.13.2）

2026-11-08。8秒境界の小さな動き・外観の段差を対象に、通常Continuumの既存CPUブレンド・安全判定を利用した固定時間の補正を追加しました。UI・モデル配線・Seed・Sampler・VAE・音声・フレーム数・時間位置は変更しません。

## 原因の切り分け

同一モデル配線/seedの2チャンクの保存済み潜在・VAE復元直後の映像と、診断OFF/reportの新規実GPU比較結果を利用しました。OFF/reportは379フレームと音声が完全一致しており、診断による段差ではありません。

トリム前のraw映像には露出パルスが存在し、既存補正で低減しています。その後も通常Continuum V3の読取解析でmotion_hitchに分類されました。Context39fとLayoutの到達検証は正常で、1〜3フレームの接合位置変更だけでは十分改善せず、通常の選択もrewind0でした。単純なトリムの1フレームずれとして扱いません。Sampling/VAE復元された境界の再現差が残っていると解釈します。H3モデル内部とVAE内部の寄与を完全に分離したという意味ではありません。

## 低RAMでの補正

- 既存の露出・色補正後に、境界変化と周辺の動きを比較します。前2フレーム・次の先頭5フレームだけを使用。
- 通常Continuum V3のmotion-hitch判定の考え方と、同梱の変更しない `choose_video_blend` / `apply_video_blend` を利用します。前2フレームの画素差で次の同じ時刻を予測し（光学フローではありません）、最大2枚だけcosineブレンドするEZ側の適用です。通常版のデコーダー全体をそのまま移植したものではありません。
- 通常ContinuumのAuto安全判定で、画素・明るさ・色・輪郭・時間差・動きの各指標に許容範囲を超える悪化がなく、5フレーム窓全体でも改善した候補だけを採用します。
- 場面転換、高速な動き、局所的な単発フラッシュ、自然な範囲の動きは維持。改善しないときは既存の補正結果を使用。
- 既に書き出したフレームを巻き戻さず、次区間の先頭だけを同じ絶対時刻で補正。通常の1チャンクDecode以上の全動画RGB確保は追加しません。入力画像の複製・予測・候補も固定枚数で、動画尺に比例しません。

この処理は最初の1〜2枚を混ぜるため、局所的な柔らかさや二重輪郭を生じる可能性があります。数値改善だけで自然さを保証せず、実映像で確認します。残りのフレームへ時間方向のフィルターを掛ける処理や、音声のクロスフェードは追加しません。

## 実GPU比較前の確認

保存済み2チャンクの復元映像では2枚の候補が採用され、既存補正後の接合スコア0.029523→0.010839、5フレーム窓の最大変化0.032740→0.023085。先頭2枚以外のprefixと入力Tensorは不変です。これは保存データ上の確認で、修正後の新規GPU生成とは区別します。

新規CPU試験は低速の段差・自然な動作・高速動作・場面転換・単発局所フラッシュ・固定窓・画像/Long video出力・入力音声/尺/派生Seed/プレビュー順を確認します。後続の実GPU比較は次節に記録しています。

## 変更しないもの

通常Continuumとvendorの原コード、登録2ノードと公開入力、テンプレート、モデル配線、Seed、音声の内容と配置、開始/終了画像、Scene Cut、既存の継続ContextとSamplingを保持します。この節は実GPU比較前の確認です。

CPU全346件・JavaScript99件成功（失敗0・スキップ0）。通常Continuum由来22モジュールと既存Workflow・モデル配線・シードを保持。ユーザー再起動後の実GPU比較は次節を参照してください。

## 修正後の実GPU確認

普段のComfyUI_Wをユーザーが再起動後、修正前と同じモデル配線・基準seed38527745983564、832×480/24fps、2区間379フレームを約359.62秒で新規GPU生成。reportでContext39f・実評価8回・失敗0を維持。

完成MP4の5フレーム窓の最大変化0.032628→0.023230（約28.8%低減）。境界frame192の推定移動量中央値2.054→0.498px、境界5フレーム内の同指標最大値2.054→1.506px。AAC682パケットの内容・PTS/DTS/長さは修正前と完全一致。フレーム数・表示時刻も維持。

フレーム列では人物・服装・座席/窓の配置を保持し、急な境界移動を低減。ただし補正2枚の柔らかさは残り、完全に無劣化・継ぎ目なしとは評価しない。実時間の聴感評価は行わず、音声はファイルデータを照合。映像の評価はフレーム列と光学フローで、ユーザー確認用の無音通常速度/スロー比較動画を別途作成。

全尺RGB1.69GiBは未確保、判定窓と候補は固定枚数。3秒間隔のプロセスRSS最大24.52GiB、起動以来のpeak working set26.28GiBを観測。モデル/VAE等を含み、補正単体の使用量や修正前とのRAM比較ではない。

この確認は1組のモデル/seed/入力音声付き2区間に限定する。新規の生成音声補正・通常Continuum/vendor改変・モデル配線変更はない。起動用一時設定は削除し、現在の検証プロセスのみreport、次回通常起動は標準OFF。v0.13.2に収録。[リリース検証記録](RELEASE_v0.13.2_VALIDATION_JA.md)を参照してください。

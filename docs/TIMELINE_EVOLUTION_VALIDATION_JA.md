- 2〜600秒・0.1秒刻みの開始／継続11,962ケースで内部フレーム数の合計を照合。差異0。
- 終了画像保持を3種類のcontextで確認。画像の開始／終了／参照の組合せを確認。
- 通常Continuumと同梱vendorは変更せず、EZの編成・UI・保存処理を変更。
- タイムライン系の参考として、[TimelineDirector](https://github.com/Songssx/ComfyUI-MiniMaxH3-TimelineDirector) と [Director](https://github.com/seesee75-commits/ComfyUI-MiniMaxH3-Director) の公開READMEも確認。これらのコードをEZのCoreへ置き換えていません。

## 独立ブラウザー

実際のStudio HTML／CSS／JSと拡張のイベント経路を使用し、ComfyUI API境界を模擬しました。日本語1880×1000と英語1280×720を確認。

- 右端ドラッグで当該秒数と後続開始位置が変わり、Undo1回で戻る。
- 左端ドラッグで前後の秒数が変わり、合計実尺15.083秒を維持。
- ドラッグ中のResizeObserverによるDOM差替えを発見し、確定まで再描画を保留する修正後に再確認。
- 長いショットを入力すると内部区間数を表示。
- 画像の呼び名、話者の画像自動選択、台詞の保持、終了画像、区間ごとの送信文を確認。最終区間にだけ終了画像の指示が入り、参照番号が実際の画像順に追従。
- ノード反映・Studioを閉じて開き直した後も設定を保持。
- 待機中／生成中／完了／失敗の表示。失敗時も完了済み部分を保持。
- 生成サムネイル15枚の画像読込み、途中MP4の再生、途中区間の開始時刻を加えたタイムライン連動。
- 例：2区間目のローカル再生時刻2.60秒に対し、タイムライン約7.76秒。再生は音声付き・ミュートなし。音声ストリームはCPU側でも確認。
- 最終MP4への切替、Studio再表示時の動画・サムネイル復帰。
- プロンプト編集で旧結果の同期とサムネイルを外し、Undoで再表示。
- 英語の各操作と説明、WAV追加・長さ取得・トラック配置。
- 両画面のconsole errorは0。

画面の動画は動く色帯とテスト音で、H3の生成結果ではありません。fixtureサーバーにはComfyUIと同じMP4 byte-range応答を用意してシークを確認しました。Alt吸着解除・Escape取消の全操作組合せ、OSスリープ、ブラウザーの切断再接続は実画面で網羅していません。

## 実環境と残る受入

稼働ComfyUIのキューが空であることと、変更前98ファイルに別の変更がないことを確認しました。適用スクリプトは、コピー直前にも変更前ファイルとバックアップの全ハッシュを照合し、別の変更があれば停止します。稼働プロセスの再起動と生成ジョブの投入は行っていません。導入後はComfyUIの通常の再起動とブラウザーの強制再読み込みが必要です。

途中再開・Second Passは対象外です。コミット・プッシュ・公開も行いません。

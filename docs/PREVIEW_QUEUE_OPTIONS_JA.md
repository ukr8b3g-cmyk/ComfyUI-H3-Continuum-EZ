# プレビュー・キュー・シード・自動分割のローカル更新

2026-11-06。EZ Studio開発版2.0.0で導入し、[公開版v0.9](RELEASE_VALIDATION_JA.md) に収録した変更です。下記の画面検証は開発版の記録です。

## 操作

- **プレビュー**：生成動画のメタデータにある幅・高さで表示領域を合わせます。縦動画を横に引き伸ばしたり、端を切り落としたりしません。プレビューパネルの広さを保ち、その中で最大限に表示します。動画左上に実サイズを表示します。編集後の「前回の動画」も元の動画比率を使います。
- **キュー表示**：Studio上部の実行ボタン横に、このTimelineのキュー待機順・実行中・完了・失敗を表示します。モデル読込みや出力保存も実行中に含まれます。Studioを開いている間だけサーバーのキューを定期確認します。
- **自動分割**：「出力の詳細設定」→「自動分割」「1区間の秒数」。既定はオン・5秒、設定範囲は2〜15秒です。分割対象は15秒を超えるショットです。15秒以下は1回で生成します。オフの場合は各ショット15秒以下が必要で、超過時はStudioとサーバーで生成前に検査します。
- **シード制御**：EZ Engineのseedをサブグラフ入力へ公開すると、外部に線がつながっていない場合に「seed · 生成後の制御」を表示します。fixed / increment / decrement / randomizeを選べます。内部の標準コントロールを操作する表示であり、独自の二重乱数処理はありません。外付けシードを接続中はそのノード側で制御します。

区間秒数は目安です。H3の時間グリッドと継続contextに合わせて調整し、合計フレーム数を保持します。例えば目標31秒・区間8秒では4区間になります。短い区間ほど生成・VAE処理を小分けにできますが、切替回数は増えます。RAM/VRAMの一定量や速度は保証しません。

## ハイブリッドモデルのエラー調査

既存ログには `Value not in list: unet_name` があり、選択値の `minimax/…safetensors` に対し登録一覧が `minimax\…safetensors` でした。同じハイブリッドモデルが登録されているにもかかわらず、パス区切りの違いでComfyUIの入力検査に失敗していました。

EZ Engineがあるワークフローでは、読込み時と標準キュー投入直前にモデル選択を確認します。区切り文字を統一したときに登録候補が一意に一致する場合だけ、その表記に合わせます。ファイル名だけの曖昧な検索、別モデルへの置換、大文字小文字の曖昧一致はしません。存在しないモデルのエラーはそのままです。

モデル名の許可リスト、hybridの一律禁止はありません。明らかに用途が違うMiniMax Music3クラスの事前検査は維持しています。未知のH3モデルの構造判定は既存Continuum処理に委ねます。この修正は、すべてのハイブリッドのREF2VA互換性を保証するものではありません。

## 実装境界

- Timeline JSONのschema 1を維持し、任意の `chunking: {enabled: true, seconds: 5}` を追加。旧設定はオン・5秒相当です。
- 分割後の継続context、seed派生、音声配置、台詞の区間割当、最終区間の終了画像は既存処理を利用。
- `/queue` の実行・待機情報を、ワークフローID、Timelineの実行ID、出力への接続で照合。別ワークフローの同じノード番号を混同しません。
- シード制御の表示は内部の標準widgetへ同期。表示専用widgetを入力値としてシリアライズしません。
- モデル・Loader・queuePromptのグローバル置換なし。通常Continuumとvendorの15ファイルは変更していません。
- シードの実行後更新は[ComfyUI frontend 1.57.6の標準処理](https://github.com/Comfy-Org/ComfyUI_frontend/blob/v1.57.6/src/core/graph/subgraph/promotedWidgetControl.ts)が担当します。

| 実ComfyUI Classic | frontend 1.57.6、独立したテスト用ワークフローでサブグラフのシード制御を表示。randomize→incrementへ変更し、エクスポートJSONの内部Engineにもincrementが保存されることを確認 |
| モデルパス | 実ログと実際のUNETLoader候補を照合。テスト用JSONのエクスポートでも登録表記へ統一されていることを確認 |

分離画面のComfyUI接続・キューイベントは模擬しています。実H3モデルで今回の設定を使ったGPU生成、生成後のseed更新、Nodes 2.0、長尺のピークRAM/VRAMは未検証です。実行中のユーザーの生成処理は停止せず、こちらからQueue投入や再起動は行っていません。

適用後は、実行中の生成が終了してからComfyUIを再起動し、ブラウザーを強制更新してください。既存のワークフロー、外付けシード、未反映のStudio編集内容は自動で配線変更・上書きしません。

# EZ contributor boundary
- Preserve the original Continuum low-level algorithms and their provenance manifest. No replacement with the former EZ masked-prefix engine.
- Do not edit user Runs/Takes or the ordinary Continuum installation.
- Keep Timeline and Engine as the only registered nodes. No global prototype/model patches.
- No new runtime dependencies, automatic installs, network services, registry publication or destructive file operations without authorization.
- Keep draft/committed state explicit; never truncate/translate prompts or silently mix/replace original audio.
- Reuse tests, run package hashes, and report CPU/standalone browser/live ComfyUI/Windows/GPU separately.
- Do not call a release GPU-accepted based on fixtures. Commit/push/publish only on explicit request.
